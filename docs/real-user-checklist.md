# Friendsgiving real-user check

Goal: a real host sends real invites to 2–3 friends, and we write down where anyone got stuck. This is the first full test with real people (evidence level 4).
Do it before Thanksgiving (Thu Nov 26) so there's time to fix anything.

## Before (host, about 10 minutes)
- [ ] Make the real plan on your phone: a name, the date with an end time, the address (pick it from the search), and 4–6 bring-list items.
- [ ] People → Add names to the guest list. Type 2–3 friends' first names.
- [ ] More tools → Get my host link. Save it in Notes. It's your backup if you change phones.

## Send (host)
- [ ] People → Send invites → next to each name, Prepare personal link, then Send. Messages opens with their own text, and you tap Send.
- [ ] In Messages, did the text show the m.o picture preview?

## What each guest does
Don't help them. Watch if you're together, or ask afterward.
- [ ] They tap the link. Does it open without zooming in or signing in?
- [ ] They tap I'm in (or Still checking).
- [ ] They see the address right after answering. This is new: they were invited by name.
- [ ] Bring list → I can bring this on one item.
- [ ] Optional: Add to calendar, or open the address in Maps.
- [ ] Optional: one guest taps "Bringing someone?" and asks to bring a friend, so you see the request.

## Host checks afterward
- [ ] Plans: is your plan listed with the right date and numbers?
- [ ] People: does each guest show the right answer? Can you tell who's bringing what?
- [ ] If someone answered you by text instead: People → Update answer next to their name. Then ask them to open their link and check they can confirm it.

## Ask each guest (by text is fine)
1. Was anything confusing or slow?
2. Did you have to ask me anything to finish?
3. What phone and app did you open it in? (For example: iPhone in Messages, Android, or inside Instagram.)

## Write down for me
- For each problem: who (first name only), which step, what they saw, and a screenshot if you can.
- Don't send me guests' phone numbers or full names.
- When you're done, come back and say **"results"**. I'll log it as real-user evidence and fix what broke.

## If something goes wrong during the check
- **A guest's link doesn't open:** People → Send invites → Replace personal link next to their name, then send it again.
- **A guest can't see the address after answering:** People → Approve arrival access next to their name.
- **The site is down:** GitHub should email you an alert. Tell me, and keep planning over text in the meantime.
